## 🦅 مسکات رسمی: «گریفی» بچه شیردال افسانه‌ای (Meet Griffi)
**گریفی (Griffi)**، بچه شیردال افسانه‌ای ایران‌باستن با چشمان زمردین، بال‌های پروانه‌ای و نشان تخت‌جمشید، مسکات و هوش‌مصنوعی راهنمای گریفین‌سواپ است. گریفی در تمام تب‌ها، پنجره‌های سواپ، هشدارها و تورهای تعاملی در کنار کاربر حضور دارد تا پیچیده‌ترین مفاهیم دیفای را به زبانی ساده و لذت‌بخش آموزش دهد.

## 🌟 امکانات پرچمدار گریفین‌سواپ (Flagship Features)

### ۱. مبادله سریع چندزنجیره‌ای و سفارشات لیمیت بدون گس (Cross-Chain Swap & In-Card Limit Orders)
- **سواپ سریع با بیش از ۵۸ بلاک‌چین**: تجمیع خودکار نقدینگی از طریق ۳۵ پل ارتباطی (Across V3، Stargate V2 و شبکه‌های امن چندزنجیره‌ای) و ۳۰ صرافی غیرمتمرکز (Uniswap، 1inch، PancakeSwap).
- **دفتر سفارش لیمیت درون کارت (In-Card Limit Order Book)**: ثبت و لغو سفارش‌های خرید/فروش شرطی بدون پرداخت حتی ۱ ریال کارمزد گس به لطف امضای آف‌چین EIP-712 Permit2.
- **حالت بدون نیاز به اتریوم (Gasless Permit2 Meta-Tx)**: امکان انجام تراکنش برای کاربرانی که فقط تتر دارند بدون نیاز به موجودی ETH؛ کارمزد شبکه مستقیماً از تتر کسر می‌شود.
- **شبیه‌سازی امنیتی پیش از تراکنش (TxPreFlightModal)**: تست بایت‌کد در محیط شبیه‌ساز برای محافظت در برابر خطای گس و لغزش قیمت.
- **رهگیری زنده ۳ مرحله‌ای بین‌زنجیره‌ای (CrossChainTrackerModal)**: رصد زنده مرحله انتشار در شبکه مبدأ، رله چندزنجیره‌ای و تسویه در شبکه مقصد به همراه جشن پاداش وفاداری گریفی.

### ۲. سکوی پرتاب عادلانه و ریخته‌گری توکن با باندینگ کرو (Fair Launchpad & Token Forge)
- **راه‌اندازی فوری توکن و میم‌کوین**: ساخت توکن پروژه در چند ثانیه با هزینه ۱۰ تتر و بدون نیاز به دانش برنامه‌نویسی.
- **مکانیزم منحنی قیمت (Bonding Curve)**: افزایش خودکار قیمت با هر خرید؛ به محض رسیدن ارزش بازار به ۶۹,۰۰۰ دلار، نقدینگی به طور خودکار به صرافی رسمی منتقل شده و توکن‌های LP سوزانده می‌شوند (ضد راگ‌پول ۱۰۰٪).
- **پشتیبانی از شبکه‌های ارزان**: آربیتروم (Arbitrum One)، بیس (Base) و پالیگان (Polygon).

### ۳. معاملات تعهدی و فیوچرز دائمی غیرمتمرکز با اهرم ۵۰ برابری (Perpetual Futures up to 50x)
- **پوزیشن‌های Long و Short بدون نیاز به احراز هویت (Zero KYC)**: معامله جفت‌ارزهای BTC-PERP، ETH-PERP، PAXG-PERP، SOL-PERP و ARB-PERP با اهرم شناور تا ۵۰x.
- **محاسبه‌گر زنده قیمت لیکوئید شدن**: هشدار صوتی و تصویری هنگام نزدیک شدن بازار به قیمت تصفیه.
- **شمارشگر معکوس نرخ فاندینگ (Funding Rate Countdown)** و ثبت تاریخچه پوزیشن‌ها به صورت غیرحضانتی.

### ۴. کارت‌های اعتباری وب۳ و گیفت‌کارت‌های بین‌المللی (Web3 Virtual Cards & Global Vouchers)
- **مسترکارت‌های مجازی اعتباری (Prepaid Mastercards)**: شارژ مستقیم با تتر (USDT) برای پرداخت سرورهای خارجی، ثبت‌نام در وب‌سایت‌های بین‌المللی و رزرو هتل.
- **ووچرهای آنی هوش مصنوعی و ارتباطات**: خرید اشتراک ChatGPT Plus، Claude Pro، تلگرام پریمیوم (Telegram Premium) و گیفت‌کارت اپل آیتونز با تحویل آنی کد لایسنس بر بستر قرارداد هوشمند.

### ۵. دامنه‌های دائمی وب۳ و هویت ماندگار (Griffin Web3 Domains)
- **ثبت دامنه‌های ماندگار `tehran.griffi` و `.iran`**: ثبت نام‌های کاربری کوتاه وب۳ به جای آدرس‌های طولانی `0x...`.
- **بدون هزینه تمدید سالانه (Lifetime Ownership)**: صفر دلار هزینه تمدید سالانه (برخلاف ENS اتریوم).
- **پاسپورت هویت NFT**: صدور آنی مدال هویتی بر بستر شبکه آربیتروم با کارمزد گس ناچیز.

### ۶. میز هجینگ طلای دیجیتال و حباب‌سنج سکه امامی (Digital Gold Hedging Desk)
- **خرید طلای دیجیتال (PAXG / XAUT) با حباب صفر درصد**: سرمایه‌گذاری در طلای با پشتوانه شمش فیزیکی لندن بدون پرداخت حباب ۱۸ درصدی سکه بازار سنتی تهران.
- **ماشین‌حساب مقایسه حباب سکه و انس جهانی**: نمایش زنده تفاوت بازدهی طلا در برابر تورم و افت ارزش ریال.

### ۷. اسکرو هوشمند همتا‌به‌همتا (P2P Non-Custodial Smart Escrow)
- **خرید و فروش مستقیم تتر به تومان**: تبادل امن تتر با صرافان تایید‌شده از طریق پرداخت کارت‌به‌کارت، پایا و ساتنا.
- **قفل خودکار دارایی در قرارداد هوشمند**: آزادسازی ارز فقط پس از تایید دریافت وجه ریالی و شناسه بانکی معتبر با زمان‌سنج ۱۵ دقیقه‌ای.

### ۸. دیدبان آربیتراژ تتر در صرافی‌های ایرانی (Arbitrage Radar)
- **رصد زنده اختلاف قیمت تتر**: پایش تفاوت قیمت میان نوبیتکس (Nobitex)، والکس (Wallex)، تترلند (TetherLand) و آبان‌تتر (AbanTether).
- **ماشین‌حساب سود خالص غیرحضانتی**: محاسبه سود انتقال به تفکیک کارمزد شبکه و کارمزد پلتفرم.

### ۹. خرید پله‌ای و مبارزه با تورم (Systematic DCA Terminal)
- **طراحی برنامه سرمایه‌گذاری منظم**: تعریف سبد پس‌انداز تومانی در افق‌های زمانی ۶، ۱۲ و ۲۴ ماهه برای بیت‌کوین، اتریوم، طلای دیجیتال و توکن شیردال.

### ۱۰. مینی‌اپ تلگرام و بریج اختصاصی شبکه تون (Telegram MiniApp & TON Bridge)
- **سواپ مستقیم درون تلگرام (`@GriffinSwapBot`)**: رابط کاربری اختصاصی برای تبادل دارایی‌های شبکه TON و تتر لایه دو.
- **تنظیمات اعلانات فوری تلگرام**: دریافت آلارم‌های قیمت تتر، ساعات طلایی افت گس و تسویه سفارش‌ها.

### ۱۱. باشگاه وفاداری گریفی (Griffi Loyalty Club & Feathers)
- **کسب امتیاز پر گریفی (Feather Rewards)** به ازای هر تراکنش، بریج یا فعالیت اجتماعی.
- **تخفیف پله‌ای کارمزد**: کاهش کارمزد سواپ از ۰.۵٪ به ۰.۲۵٪ بر اساس رتبه وفاداری (برنزی، نقره‌ای، طلایی و شیردال سلطنتی).

### ۱۲. مرکز امنیت، حریم خصوصی و ضدتحریم (Anti-Censorship & Security Hub)
- **نودهای آزاد RPC**: ارائه‌دهندگان 1RPC، Cloudflare، LlamaNodes و Flashbots برای دور زدن خطای ۴۰۳ ناشی از تحریم‌های Infura و Alchemy.
- **دیدبان هانی‌پات و ممیزی قراردادها (Honeypot Scanner)**: بررسی مالیات خرید/فروش، بلک‌لیست و امکان راگ‌پول توکن‌ها پیش از خرید.
- **ابزار ابطال دسترسی ولت (Revoke Tool)** برای پاکسازی دسترسی‌های نامحدود قراردادهای قدیمی.

## 🚀 راهنمای راه‌اندازی و اجرا (Quick Start)

### ۱. پیش‌نیازها:
- Node.js نسخه ۲۰ یا بالاتر
- npm نسخه ۱۰ یا بالاتر

### ۲. نصب وابستگی‌ها:
```bash
# نصب پکیج‌های اصلی
npm install
npm --prefix frontend install
npm --prefix Project/Backend install
```

### ۳. اجرای همزمان سرور و فرانت‌اند:
```bash
# اجرای بک‌اند (پورت 5001)
npm run start:backend

# اجرای فرانت‌اند در ترمینال مجزا (پورت 3000)
npm run dev:frontend
```
پس از اجرا، مرورگر را در آدرس `http://localhost:3000` باز کنید.

### ۴. بیلد نهایی محیط عملیاتی (Production Build):
```bash
npm run build:frontend
```

## 🔒 امنیت، حریم خصوصی و مقاومت در برابر سانسور
- **عدم ذخیره کلید خصوصی**: تمامی تراکنش‌ها توسط ولت شخصی کاربر (Rabby، MetaMask، TrustWallet) امضا می‌شوند.
- **فال‌بک فونت ضدتحریم**: فونت وزیرمتن علاوه بر CDN گوگل، به صورت مستقیم از طریق CDN بدون تحریم داخلی (`cdn.jsdelivr.net`) لود می‌شود تا در زمان اختلالات اینترنت بین‌الملل بدون نقص نمایش داده شود.
- **ساختار داده سئو (JSON-LD Schemas)**: مجهز به اسکیمای غنی FAQPage، FinancialService و WebSite به زبان فارسی و انگلیسی برای کسب برترین رتبه در موتورهای جستجو.
